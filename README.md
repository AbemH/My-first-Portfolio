# My First Portfolio

This is my personal portfolio website, where I introduce myself, share some of my skills, and showcase projects I have worked on while learning software engineering and web development.

## Technologies Used

- HTML
- CSS
- JavaScript
- Google Fonts

## Features

- Personal introduction and about section
- Skills and courses section
- Featured projects
- Contact form with a front-end confirmation message
- Responsive design
- Background video
- Navigation bar with scroll effects

## How to Run

Open `Portfolio/portfolio/index.html` in your browser.
